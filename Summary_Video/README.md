# Summary Video

`Bounding_the_Adhesive_Bond__Planning_and_Perception.mp4` — an AI-generated
video overview of this thesis, produced by Google NotebookLM's Video
Overview feature from the thesis PDF, a written summary, and this
repository as sources.

**This is not real footage.** Every visual in this video — the gripper,
the sensor, the robot arm, all of it — is generated by NotebookLM's
underlying image/video models, not pulled from the actual hardware. For
real photos and video of the physical gripper, test rig, and experiments,
see `Experiments/` and `Grasp_Validation/hardware_validation/` instead.
For real simulated trajectories from the motion planner, see
`Simulation_Results/Scenario_Bank/`.

## Why an AI-generated video at all

NotebookLM can't incorporate uploaded photos or video clips into its
output — its Video Overview feature generates every frame fresh, so no
prompt can make it use real footage directly. This version exists as a
narrated, illustrated summary for a general audience, alongside the real
media elsewhere in this repository rather than in place of it.

## On accuracy

The content was checked frame-by-frame across the full video before being
added here (not just generated and uploaded untested). An earlier
generation attempt was rejected for showing the wrong gripper mechanism
entirely — a mechanical claw and a camera/laser sensor, when this thesis's
gripper is a flat adhesive pad and the sensor is a small photoresistor
array. This version was regenerated with explicit instructions against
those errors, and checked again: the gripper is consistently shown as a
flat pad, the sensor array and classifier architecture are shown
accurately (correctly labeled as a 4-input network, correctly labeled
"15-Frame Temporal Window" matching the real sequence model), and one
segment displays the actual source text on screen rather than an
illustration. One minor imperfection remains — a brief shot around the
4-minute mark shows the pad with small tab-like details suggestive of
mechanical gripping — noted here rather than left for a viewer to spot
unremarked.

**The narration audio was not independently verified.** Transcribing it
would have required a speech-to-text model, and every one available
needs a download from a host outside this environment's network access.
The accuracy check above covers the visuals only.
